Component library

Every component is a custom element: drop the tag in and it works. They read the brand tokens from unplug-tokens.css, so nothing here hard-codes a colour, and they all honour prefers-reduced-motion — which is one rule in the token file rather than a decision each component makes separately.

The markup works without the script. An accordion is headings and sections; if unplug-components.js fails to load, the content is still readable.

Accordion

<unplug-accordion open-first>
  <h3 slot="title">How do I enter?</h3>
  <div>Nominate someone from the Top 10 page.</div>
</unplug-accordion>

Each heading is a real <button> inside the heading level you wrote, so the document outline survives and a screen reader announces "button, collapsed". Arrow keys are deliberately left alone — for disclosures the expected key is Tab, and hijacking arrows breaks scrolling for keyboard users.

Countdown

<unplug-countdown to="2026-12-25T00:00:00+02:00" finished="Entries closed"></unplug-countdown>

The digits tick every second; the screen-reader announcement is polite and only changes when the minutes do. A live region updating every second would have a screen reader reciting numbers for ever.

Lightbox

<unplug-lightbox><img src="…" alt="…"></unplug-lightbox>

Focus moves into the dialog, is trapped while it is open, and returns to the thumbnail on close. Escape closes, arrows move between images, and a swipe works on a phone. A dialog somebody can Tab out of into a page they cannot see is worse than no dialog.

Click to share

<unplug-tweet text="…" url="…"></unplug-tweet>

A link, not a third-party script. The official button loads code from another company on every page it appears on, which costs a request and tells them who read the article.

Testimonials

<unplug-testimonials><figure><blockquote>…</blockquote><figcaption>…</figcaption></figure></unplug-testimonials>

A list, not a carousel. Rotating quotes lose the reader mid-sentence and give a screen reader whichever one happens to be showing.
